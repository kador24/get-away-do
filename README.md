# بوت وظائف القناة — الجزائر

يرسل الوظائف الجديدة بشكل احترافي إلى قناة تليجرام كل 4 ساعات.

## المميزات
- كشط منصات جزائرية (Emploitic, Bayt, Ouedkniss, BeBee, JobsDZ)
- فلترة حسب كلمات ديبلوم / ليسانس / تخصصات
- منع التكرار (لا ترسل نفس الوظيفة مرتين)
- إرسال للقناة مع صورة (لوغو) إن وُجدت
- أمر يدوي `/run` للأدمن فقط

## التثبيت
```bash
cd jobs_channel_bot
npm install
```

## إضافة اللوغو
ضع صورتك في:
```
assets/logo.jpg
```
(يفضل JPG أو PNG)

## التشغيل
```bash
npm start
```

## أوامر الأدمن (في المحادثة الخاصة مع البوت)
- `/run` — كشط يدوي مرة واحدة
- `/status` — الحالة
- `/stop` — إيقاف الجدولة
- `/help` — المساعدة

## الإعدادات
عدّل `config/settings.json`:
- channelId
- keywords
- scrapeInterval (حالياً كل 4 ساعات)
